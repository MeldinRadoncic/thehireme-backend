# TheHireMe - Backend

**GitHub Repository:** https://github.com/MeldinRadoncic/thehireme-backend

## Project Overview
Supabase backend for TheHireMe platform. Contains:
- Database migrations
- Edge Functions
- Database seeding
- Shared data layer for client, worker, and admin projects

## Project Structure
```
supabase/
  ├── migrations/     # Database migrations
  ├── functions/      # Edge Functions
  └── seed.sql        # Database seed data
```

## Getting Started
```bash
npm install
npm run dev
```
